🧠 Memoria y Sinónimos

El sistema puede aprender equivalencias de términos:

Ejemplos:
• "Guarda en tu memoria que molino eólico es igual a WTG y aerogenerador"
• "Recuerda que inversor es lo mismo que convertidor"
• "Central = Parque = Planta"

Una vez guardados, cuando busques con cualquiera de estos términos, el sistema expandirá automáticamente la búsqueda a todos los sinónimos.

⚡ Tips de Uso

✓ Sé específico: "Central Kosten" funciona mejor que solo "Kosten"
✓ Usa contexto: El sistema recuerda conversaciones anteriores
✓ Referencias: Puedes pedir "Explícame más sobre [Anexo D, página 3]"
✓ Múltiples preguntas: Puedes hacer varias consultas relacionadas
✓ Correcciones: Si la respuesta no es clara, reformula la pregunta
✓ Documentos: El sistema indexa 50+ PDFs de protocolos CROM

🎯 Capacidades del Sistema

• Búsqueda Híbrida: Combina búsqueda semántica y por palabras clave
• Memoria de Conversación: Recuerda el contexto de tus preguntas
• Extracción de Datos: Puede extraer tablas y listas de documentos
• Referencias: Cita las fuentes (documentos y páginas)
• RAG con LLM: Usa Llama 3.1 local para generar respuestas
